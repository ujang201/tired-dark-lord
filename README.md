A program that writes one 100-word monologue to `/output/entry.txt`, spoken by a fantasy villain who is secretly just very tired. The tiredness lives in the pauses, the trailing thoughts and the small deflections — never in a plain statement. He has kept the Ember Crown burning for thirty years, forgot to crush a rebellion, and keeps his generals waiting in the hall.

Run it with `node main.ts`. It writes the monologue deterministically — the same bytes on every run — and checks its own word count (about 100) and the 1–600 character gate before writing.
